# Getting help

- **Questions and help with installing:** the [Help room](https://matrix.to/#/#overpressure-help:matrix.org) of
  the project's Matrix space, [#overpressure:matrix.org](https://matrix.to/#/#overpressure:matrix.org); each
  headset has its own room there.
- **Bugs and feature requests:** an issue in the repository they concern (the headset's for its system and
  drivers, [overpressure](https://github.com/overpressure/overpressure/issues/new/choose) for the installer).
- **Security vulnerabilities:** privately, as [SECURITY.md](SECURITY.md) says, never in chat or an issue.
